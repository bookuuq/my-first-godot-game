# 碰撞检测 (Collision Detection)

> 2026-07-26 · Godot 4.7 · 2D

---

## 核心概念

你可以把碰撞检测想象成**两个人在黑屋子里走路**——碰撞检测就是「判断两个人有没有撞到一起」，碰撞响应就是「撞到之后怎么处理」。

在 Godot 里，这不是写一堆数学判断，而是用**物理节点**来实现。每个物体被一个看不见的「形状」（圆形、矩形等）包裹着，引擎自动帮我们计算它们什么时候碰上了。

---

## 四种碰撞节点，选哪个？

| 节点 | 比喻 | 最适合 |
|------|------|--------|
| **CharacterBody2D** | 你自己控制的角色 | Player、Enemy 的移动 |
| **StaticBody2D** | 墙壁、地板、柱子 | 不会动的障碍物 |
| **Area2D** | 一扇感应门 | 金币、伤害区域、检测范围 |
| **RigidBody2D** | 一个被人推着滚的球 | 需要模拟真实物理的物体 |

你现在做的 Player 用的是 `ColorRect` + 手动 `position` 移动，这其实**不是**用物理节点。下一步你只需要把玩家从 `ColorRect` 改成 `CharacterBody2D`，再给敌人一个 `Area2D` 来检测碰到玩家。

---

## 实战：给你的项目加碰撞检测

### 改造 Player（使用 CharacterBody2D）

```gdscript
extends CharacterBody2D

var speed = 400

func _physics_process(delta):
    var direction = Vector2.ZERO
    
    if Input.is_action_pressed("ui_right"):
        direction.x += 1
    if Input.is_action_pressed("ui_left"):
        direction.x -= 1
    if Input.is_action_pressed("ui_down"):
        direction.y += 1
    if Input.is_action_pressed("ui_up"):
        direction.y -= 1
    
    velocity = direction * speed
    move_and_slide()
    
    # 边界限制
    var screen_size = get_viewport_rect().size
    position.x = clamp(position.x, 0, screen_size.x - 64)
    position.y = clamp(position.y, 0, screen_size.y - 64)
```

关键变化：
- 继承 `CharacterBody2D` 而不是 `ColorRect`
- 用 `velocity` 和 `move_and_slide()` 代替 `position += direction * speed * delta`
- 需要在 `_physics_process` 而不是 `_process` 里运行

### 检测敌人碰到玩家（Area2D 信号）

给 Enemy 节点加一个 `Area2D` 子节点和一个 `CollisionShape2D`，然后：

```gdscript
# 连接到 Area2D 的 body_entered 信号
func _on_area_2d_body_entered(body):
    if body.is_in_group("player"):
        print("敌人碰到玩家了！")
        # 后面可以加：扣血、重置位置等
```

## 几个新人容易忽略的点

1. **CollisionShape2D 必须有形状** —— 在 Inspector 里选一个 Shape，否则就是个「透明」的，什么都检测不到
2. **形状不要缩放** —— 调整 Shape 本身的大小，不要调整节点 Scale
3. **碰撞层 (Layer) 和遮罩 (Mask)** —— Layer 是「我是谁」，Mask 是「我要和谁碰撞」
4. **_physics_process vs _process** —— 物理相关代码放前者（每秒固定 60 帧），其他放后者
